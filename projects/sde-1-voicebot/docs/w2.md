# W2 Speech-to-Text / Transcription

Related to [issue #4](https://github.com/neonjava/acd_voicebot/issues/4), [issue #5](https://github.com/neonjava/acd_voicebot/issues/5), and [issue #31](https://github.com/neonjava/acd_voicebot/issues/31).

The Python package is `app`, rooted at `projects/sde-1-voicebot/backend/`. W2 delivers transcript domain schemas, a provider-neutral adapter protocol, a deterministic fake transcriber, an ordered segment accumulator with revision tracking, audio preprocessing, bounded retry policies, and an end-to-end transcription orchestrator.

## Week 2 Architecture (Issue #31, Days 8–14)

Week 2 connects upstream W1 audio chunks through preprocessing, bounded retry boundaries, provider adapters, and an extended segment accumulator.

```text
[W1 AudioChunks] 
       │
       ▼
[AudioPreprocessor]  ── (amplitude normalization, resampling)
       │
       ▼
[RetryPolicy]        ── (bounded retries, positive timeout, error normalization)
       │
       ▼
[TranscriptionAdapter] (FakeTranscriber)
       │
       ▼
[TranscriptEvents]
       │
       ├──────────────────────────────────────────┐
       ▼                                          ▼
[SegmentAccumulator]                       [W5 Session Stream]
(order, revisions, deduplication, gaps)    (typed TranscriptEvent envelopes)
       │
       ▼
[W3 Reasoning Context]
(finalized TranscriptSegments -> ContextItems)
```

### 1. Transcription Orchestrator (`app.transcription.orchestrator`)

`TranscriptionOrchestrator` coordinates the full pipeline:
- **`process_chunks(chunks, session_id, correlation_id, timestamp, preprocess=True)`**:
  - Preprocesses incoming `AudioChunk` objects (amplitude normalization).
  - Invokes `TranscriptionAdapter` wrapped with `RetryPolicy`.
  - Ingests successful `TranscriptSegment` payloads into `SegmentAccumulator`.
  - Emits typed `TranscriptEvent` envelopes.
- **`get_transcript_text()`**: Returns concatenated text in chronological order.
- **`get_segments()` / `get_final_segments()`**: Returns accumulated segments ordered chronologically.
- **`get_revisions(segment_id)`**: Returns revision count for a segment ID.
- **`get_gaps(min_gap_ms)`**: Returns detected silence/pause gaps.
- **`cancel(session_id)` / `reset()`**: Safely halts or resets session state.

### 2. Audio Preprocessing (`app.transcription.preprocessing`)

Deterministic, pure-Python preprocessing for `pcm_s16le` mono audio:
- **`normalize_amplitude(pcm, target_peak=0.95)`**:
  - Scales 16-bit signed samples to target peak amplitude in `(0.0, 1.0]`.
  - Prevents clipping: clamps samples to `[-32768, 32767]`.
  - Preserves silence: all-zero PCM is returned unmodified.
- **`resample_pcm(pcm, from_rate_hz, to_rate_hz=16000)`**:
  - Linear interpolation resampling between sample rates.
  - Preserves mono 16-bit encoding deterministically.
- **`AudioPreprocessor`**:
  - `process_chunk(chunk)`: Normalizes an `AudioChunk` while keeping byte formula `duration_ms * 32` intact.
  - `convert_external_audio(pcm, from_rate_hz, session_id, chunk_ms)`: Converts non-16kHz PCM to standard 16kHz `AudioChunk` sequences without loosening Week 1 contract validators.

### 3. Bounded Retry & Timeout Policy (`app.transcription.retry`)

- **`RetryPolicy(max_retries=2, retryable_codes=...)`**:
  - Enforces bounded attempts (`max_retries + 1`).
  - Retries transient errors (`retryable=True` or codes like `TRANSCRIPTION_TEMPORARY_ERROR`, `TRANSCRIPTION_TIMEOUT`).
  - Immediately rejects non-retryable errors (`retryable=False`, malformed payloads) without retry.
  - When retries are exhausted, emits a normalized `TRANSCRIPTION_RETRY_EXHAUSTED` error envelope with safe user messaging.
  - Safely normalizes unexpected driver exceptions to `TRANSCRIPTION_INTERNAL_ERROR`.

### 4. Extended Segment Accumulator (`app.transcription.accumulator`)

Extended for Week 2 requirements:
- **Chronological ordering**: Sorts strictly by `(start_ms, sequence_id, segment_id)`.
- **Out-of-order arrivals**: Segments arriving out of chronological order are properly sorted.
- **Revision tracking**: Updates text on the same `segment_id` and records `revisions_count(segment_id)`.
- **Stale interim rejection**: Interim updates with a lower `sequence_id` arriving after a newer interim are dropped.
- **Regression prevention**: Final segments cannot regress back to interim.
- **Duplicate suppression**: Exact duplicate events are ignored without duplicate text or revision increments.
- **Gap detection**: `gaps(min_gap_ms)` identifies silence or pauses between segments.
- **Session safety**: Rejects events with mixed `session_id`s with `ValueError`.

## Transcription Contracts (`app.contracts.transcription`)

Inherits from shared models in `app.contracts.common`:

- **`TranscriptSegment`**:
  - `segment_id`: Nonempty string (`min_length=1`, pattern `r"\S"`).
  - `session_id`: Nonempty string (`min_length=1`, pattern `r"\S"`).
  - `sequence_id`: Strict integer `>= 0`.
  - `start_ms` / `end_ms`: Strict integers `>= 0`, enforcing `end_ms >= start_ms`.
  - `text`: Nonblank recognized or synthetic transcript text.
  - `confidence`: Finite float in `[0.0, 1.0]` or `None`.
  - `language`: Nonempty language tag (default `"en"`).
  - `is_final`: Strict boolean indicating interim vs final status.
  - `extra="forbid"`: Rejects unknown fields.

- **`TranscriptEvent`**: Typed envelope inheriting `EventEnvelope[Union[TranscriptSegment, ErrorEnvelope]]`.
  - `producer`: Literal `"transcription"`.
  - `event_type`: Literal `"transcript.segment"` or `"transcript.error"`.
  - `schema_version`: Literal `"1.0"`.
  - Strict pairing:
    - `"transcript.segment"` requires `payload: TranscriptSegment` and matching `session_id`.
    - `"transcript.error"` requires `payload: ErrorEnvelope` and matching `correlation_id`.
  - Enforces timezone-aware UTC timestamp.

## Integration & Handoffs

- **W1 (Audio):** Consumes real `make_fake_pcm` and `chunk_pcm`. `AudioPreprocessor` normalizes amplitude and resamples non-16kHz external audio without weakening canonical 16kHz `AudioChunk` validation.
- **W3 (Reasoning):** `TranscriptionOrchestrator.get_final_segments()` outputs finalized `TranscriptSegment` objects mapped via `context_item_from_transcript` into `ContextItem` with `source_id=segment_id`, `kind="transcript"`.
- **W5 (Backend & Sessions):** Emits validated `TranscriptEvent` envelopes ready for inclusion in `MockSessionResponse.events`.
- **W6 (Frontend):** Accumulator ordering and revision semantics match frontend `TranscriptTimeline` badges (`Interim`, `Final`, `Revised`).
