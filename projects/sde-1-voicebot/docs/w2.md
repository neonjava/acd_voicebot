Related to [issue #4](https://github.com/neonjava/acd_voicebot/issues/4) and [issue #5](https://github.com/neonjava/acd_voicebot/issues/5).

The Python package is `app`, rooted at `projects/sde-1-voicebot/backend/`. W2 delivers transcript domain schemas, a provider-neutral adapter protocol, a deterministic fake transcriber, an ordered segment accumulator, tests, fixtures, and a runnable demo.

## Transcription contracts (`app.contracts.transcription`)

All transcript schemas inherit from shared models defined in `app.contracts.common`:

```python
from app.contracts.transcription import TranscriptEvent, TranscriptSegment
```

- **`TranscriptSegment`**: A validated transcript segment.
  - `segment_id`: Nonempty string (`min_length=1`, pattern `r"\S"`).
  - `session_id`: Nonempty string (`min_length=1`, pattern `r"\S"`).
  - `sequence_id`: Strict integer `>= 0` (rejects booleans, floats, strings).
  - `start_ms` / `end_ms`: Strict integer milliseconds `>= 0`, enforcing `end_ms >= start_ms`.
  - `text`: Nonblank recognized or synthetic transcript text.
  - `confidence`: Finite float in `[0.0, 1.0]` or `None` when unknown (rejects `NaN`, `Inf`, out-of-range).
  - `language`: Nonempty language tag (default `"en"`).
  - `is_final`: Strict boolean indicating interim vs final status (default `True`).
  - `extra="forbid"`: Rejects unknown fields.

- **`TranscriptEvent`**: Typed envelope inheriting `EventEnvelope[Union[TranscriptSegment, ErrorEnvelope]]`.
  - `producer`: Literal `"transcription"`.
  - `event_type`: Literal `"transcript.segment"` or `"transcript.error"`.
  - `schema_version`: Literal `"1.0"`.
  - Strict pairing:
    - `"transcript.segment"` requires `payload` to be `TranscriptSegment` and enforces matching `session_id`.
    - `"transcript.error"` requires `payload` to be `ErrorEnvelope` and enforces matching `correlation_id`.
  - Enforces timezone-aware UTC timestamp.

## Provider-neutral adapter (`app.transcription.adapter`)

Defines the `TranscriptionAdapter` `@runtime_checkable` Protocol:

```python
class TranscriptionAdapter(Protocol):
    def transcribe(
        self,
        chunks: Sequence[AudioChunk],
        *,
        session_id: str,
        correlation_id: str,
        timestamp: datetime,
    ) -> list[TranscriptEvent]: ...

    def health(self) -> str: ...

    def cancel(self, session_id: str) -> None: ...
```

## Deterministic fake transcriber (`app.transcription.mock`)

`FakeTranscriber` implements `TranscriptionAdapter`:
- **Deterministic**: Works entirely in memory with synthetic text; zero network, zero paid APIs, zero device access.
- **Constructor**: Accepts positive `timeout_seconds: float = 5.0` (validated `> 0`).
- **`health()`**: Returns `"ready"`.
- **`cancel(session_id)`**: Records cancellation; subsequent calls to `transcribe()` for that session safely return `[]`.
- **`transcribe(chunks, session_id, correlation_id, timestamp)`**:
  - Empty chunks list returns `[]`.
  - Valid ordered chunks produce one final `TranscriptSegment`:
    - `text`: `"Hello from the mock voicebot."`
    - `confidence`: `1.0`
    - `language`: `"en"`
    - `start_ms` / `end_ms`: Spans the input chunks (`chunks[0].start_ms` to `chunks[-1].start_ms + chunks[-1].duration_ms`).
    - Derived IDs: `segment_id="{session_id}-segment-{index}"`, `event_id="event-transcript-{index}"`.
  - Invalid chunk sequences or mixed sessions return a safe `transcript.error` event with `ErrorEnvelope` without crashing or corrupting state.

## Ordered segment accumulator (`app.transcription.accumulator`)

`SegmentAccumulator` manages live and completed transcript segments:
- **Order preservation**: `segments()` returns segments ordered strictly by `(start_ms, sequence_id, segment_id)`.
- **Interim-to-final replacement**: Adding a final segment with an existing `segment_id` replaces the previous interim segment.
- **Regression prevention**: A final segment cannot regress back to interim status if an out-of-order interim event arrives late.
- **Duplicate suppression**: Repeated final events with the same `segment_id` do not create duplicate segments.
- **Session safety**: Rejects events from mixed `session_id`s in a single accumulator with `ValueError`.
- **Error isolation**: `transcript.error` events do not become transcript segments.
- **`text()`**: Returns the concatenated transcript text in proper chronological order.

## Limitations

- **Week 1 Mock Only**: No speech recognition neural models (Whisper/Vosk/Kaldi) or microphone devices are invoked.
- **Fixed Synthetic Text**: Deterministic mock produces `"Hello from the mock voicebot."` for valid chunk sequences.
- **In-Memory Cancellation**: Cancellation state is stored in memory; distributed cancellation or persistence is planned for future weeks.
