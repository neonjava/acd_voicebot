# W5 Backend, sessions, and shared contracts — Week 1

Related to [issue #2](https://github.com/neonjava/acd_voicebot/issues/2).

The Python package is `app`, rooted at `projects/sde-1-voicebot/backend/`. W5 provides the shared foundation, envelopes, session lifecycle service, mock FastAPI endpoints, and CI workflow for all workstreams.

## Shared contracts (`app.contracts.common`)

All domain contracts import from `app.contracts.common`:

```python
from app.contracts.common import (
    ContractModel,
    ErrorEnvelope,
    EventEnvelope,
    SessionState,
    WorkflowState,
)
```

- **`ContractModel`**: Base Pydantic v2 model configuring `extra="forbid"` to strictly reject unknown fields.
- **`EventEnvelope[T]`**: Generic event carrier with `event_id`, `event_type`, `schema_version="1.0"`, `session_id`, `correlation_id`, `timestamp` (strict timezone-aware UTC validation), `producer`, and typed `payload`.
- **`ErrorEnvelope`**: Safe error structure (`code`, `message_safe_for_user`, `retryable`, `correlation_id`, `details_redacted`). Does not leak raw tracebacks or sensitive payloads.
- **`SessionState`**: `created`, `active`, `paused`, `stopping`, `completed`, `failed`, `expired`.
- **`WorkflowState`**: `draft`, `awaiting_approval`, `running`, `paused`, `succeeded`, `failed`, `cancelled`.

## Session service & mock runner (`app.sessions.service`)

The in-memory repository manages session lifecycles and enforces the documented transition matrix:

- Minimum Week 1 path: `created -> active -> completed`.
- Rejects illegal state transitions with `InvalidSessionTransitionError`.
- `run_mock_session(*, session_id, correlation_id, timestamp)` creates and completes a finite session, emitting ordered events:
  1. `audio.chunk` (wire projection `AudioChunkMetadata` with sequence, duration, sample rate, size; no raw PCM).
  2. `transcript.segment` (synthetic final transcript event matching contracts.md).

## Endpoints (`app.main`)

FastAPI application exporting `app`:

- `GET /api/health` → `200 {"status": "ok", "mode": "mock"}`
- `GET /api/ready` → `200 {"status": "ready", "mode": "mock"}` (503 `ErrorEnvelope` if mock configuration is unavailable)
- `POST /api/sessions/mock` (body `{}`) → `201 MockSessionResponse` (rejects extra fields with 422 `ErrorEnvelope`)
- **Middleware**: Assigns unique `X-Request-ID` and validates/propagates `X-Correlation-ID` (1–128 ASCII chars `[A-Za-z0-9_-]`). Invalid client correlation IDs return 422 with a safe regenerated correlation ID.
- **Error normalization**: Exception handlers convert 422 validation errors and unhandled 500 exceptions into typed `ErrorEnvelope` objects.

## Shared fixture (`backend/tests/fixtures/session_response.json`)

Exported from `run_mock_session` with fixed baseline parameters (`session-demo`, `correlation-demo`, `2026-01-01T00:00:00Z`). Used by Ruthwin (W6) to test frontend rendering against the exact wire schema without requiring a running server.

## Integration & handoffs

- **W1 (Audio):** Unblocked. W1 contracts import `ContractModel` and `ErrorEnvelope` from `app.contracts.common`.
- **W2 (Transcription):** Unblocked. W2 consumes `AudioChunk` and produces `TranscriptEvent` wrapping `TranscriptSegment`.
- **W3 & W4 (Reasoning & Agent):** Unblocked. Can define domain schemas inheriting `ContractModel` and reference `WorkflowState`.
- **W6 (Frontend):** Consumes `session_response.json` fixture and connects client to `/api/sessions/mock`.
